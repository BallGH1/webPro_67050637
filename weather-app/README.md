เป็น Web App ดึง API พยากรณ์อากาศมาโชว์ครับ โดยสามารถ Search ชื่อจังหวัดได้ และจะแสดงข้อมูลพยากรณ์อากาศย์ของ ณ เวลานั้นๆ และ แสดง 5 วัน ถัดไปด้วย ผมไม่แน่ใจว่าอาจารย์ให้ Mock รึเปล่า แต่ผมอยากลองเฉยๆ ผมเลยไปยิง Request ไปอีกเส้นเพื่อดึงข้อมูลพยากรณ์อากาศล่วงหน้า 5 วันมาแสดงด้วยครับ ส่วนรูปผมก็ดึงรูปมาจาก API เลย และทำฟังก์ชันแบบดูหลายเมืองได้ด้วยครับ โดยสมมุติเรากรอก  Bangkok,Chiang Mai เราจะเอาไปเก็บไว้ใน cities แล้วจะยิง API Request ไป แล้วจะได้ response กลับมาใส่ใน result โดยจะได้ข้อมูล เป็น 2ใบ ทั้ง Bangkok,Chiang Mai ในทีเดียวครับ
